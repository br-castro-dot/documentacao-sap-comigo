Visão Geral da Integração

Seja bem-vindo à documentação base de integração entre os sistemas SAP da COMIGO e a plataforma Studion.mx, desenvolvida pela DOT Digital Group.

Este documento serve como guia técnico para orientar a equipe de engenharia no consumo dos serviços de consulta de cursos, trilhas e o status de matrículas dos usuários. Todos os endpoints mapeados no menu lateral correspondem estritamente aos escopos e fluxos combinados e acordados no documento técnico inicial do projeto.

URL Base (Host)

Para realizar as requisições de teste e homologação do projeto, utilize o seguinte endereço de servidor:

https://api-studion-sescoop.hom.dotgroup.com.br
📝 Nota Importante sobre as Rotas: A URL base descrita acima deve, obrigatoriamente, anteceder (ficar antes) de todos os caminhos relativos dos endpoints listados nesta documentação.

Exemplo prático: Se o endpoint de autenticação está mapeado como /api/login_check, a requisição final contendo o Host completo deverá ser disparada para:
https://api-studion-sescoop.hom.dotgroup.com.br/api/login_check

Fluxo de Integração Sugerido

Para um consumo correto e ordenado dos endpoints, recomendamos seguir a seguinte esteira lógica de desenvolvimento:

  • 1. Autenticação: Realize a chamada enviando as credenciais para obter o Bearer Token (JWT).
  • 2. Listagens e Consultas: Navegue pela estrutura de Cursos e Trilhas utilizando os IDs para buscar informações detalhadas.
  • 3. Validação de Matrícula: Utilize os endpoints de busca passando parâmetros como email ou username para verificar o status e o progresso do usuário no respectivo conteúdo.

Autenticar Usuário

Gera os tokens de acesso (Access Token) e de atualização (Refresh Token) a partir das credenciais do usuário. Este token será necessário para autenticar as requisições nos demais endpoints protegidos da API.

POST /api/login_check

Cabeçalhos (Headers)

NomeTipoDescrição
Content-Type String Obrigatório. Valor deve ser application/x-www-form-urlencoded.
⚠️ Atenção: Certifique-se de enviar os dados no formato x-www-form-urlencoded. Enviar como application/json resultará em erro.

Corpo da Requisição

ParâmetroTipoDescrição
_username String Obrigatório. O e-mail de acesso do usuário.
_password String Obrigatório. A senha de acesso do usuário.

Respostas

200 OK (Sucesso)

{
    "token": "eyJhbGciOiJSUzI1NiIsInR5...[JWT Omitido]",
    "refresh_token": "eyJhbGciOiJIUzUxMiIsInR5...[Refresh Token Omitido]"
}

Exemplo cURL

curl --location 'https://api-studion-sescoop.hom.dotgroup.com.br/api/login_check' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode '_username=SEU_USUARIO' \
--data-urlencode '_password=SUA_SENHA'

Buscar Usuário por E-mail

Retorna as informações detalhadas de um usuário cadastrado a partir do seu e-mail.

💡 Nota de Cache: Os dados de retorno deste endpoint passam por um mecanismo de cache interno com duração de até 1 semana. Alterações muito recentes no cadastro do usuário podem ter um leve atraso de sincronização nesta chamada.
🔑 Importante: Esta requisição retorna o campo uuid. O valor deste campo será obrigatório para realizar a matrícula do usuário em uma trilha ou curso.

Download de Certificado de Curso

Realiza o download do arquivo do certificado de conclusão referente a uma sessão/curso avulso. O sistema busca o histórico de aprovação validando o certificate_hash informado.

GET /api/myself/session/certificate/download/{certificate_hash}

Cabeçalhos (Headers)

NomeTipoDescrição
Authorization String Obrigatório. Bearer <seu_token_jwt>
Accept String Opcional. É recomendado enviar application/pdf.

Parâmetros de URL

ParâmetroTipoDescrição
certificate_hash String Obrigatório. O hash/UUID de validação único do certificado gerado no momento da conclusão.

Respostas

200 OK (Sucesso)

A requisição retorna o conteúdo binário do documento em PDF. Se o integrador estiver utilizando JavaScript (Axios/Fetch), é crucial configurar a resposta do HTTP Client para aceitar BLOB (ex: responseType: 'blob').

404 Not Found

Pode ocorrer caso o hash informado não exista, ou caso a camada de histórico não encontre dados atrelados àquele hash.

{
    "message": "hash_not_found",
    "code": 404
}

Exemplo cURL

curl --location 'https://api-studion-sescoop.hom.dotgroup.com.br/api/myself/session/certificate/download/0a41a259-8a8a-46c4-bf9f-a334d5d07a62' \
--header 'Accept: application/pdf' \
--header 'Authorization: Bearer SEU_TOKEN_JWT_AQUI'

Buscar Matrícula na Trilha

Busca e retorna as informações de matrícula de um usuário específico em uma trilha, filtrando a busca por e-mail e ativando a resposta formatada na versão V2.

GET /api/paths/{path_id}/enroll?query[email]={email_do_aluno}

Cabeçalhos (Headers)

NomeTipoDescrição
Authorization String Obrigatório. Bearer <seu_token_jwt>
X-Accept-Version String Obrigatório. Utilize o valor v2 para garantir a estrutura correta de retorno da API para esta busca específica.

Parâmetros de URL & Query

ParâmetroTipoDescrição
path_id (URL) Integer Obrigatório. O ID numérico da trilha consultada (Ex: 3335).
query[email] (Query) String Obrigatório. O e-mail do aluno para filtrar o registro de matrícula exato. (Ex: aluno@email.com).

Respostas

200 OK (Sucesso)

O retorno injeta dados computados no momento da busca, como canReEnroll (calculado baseado nas regras da trilha) e enrollDeadline (baseado no primeiro acesso + duração da trilha).

            "email": "aluno@email.com",

            "certificate_issued_at": "2026-05-19T10:00:00+00:00",
            "certificate_downloaded_at": null,
            "groups": []
        }
    ]
}

curl --location -g 'https://api-studion-sescoop.hom.dotgroup.com.br/api/paths/3335/enroll?query[email]=aluno@email.com' \
